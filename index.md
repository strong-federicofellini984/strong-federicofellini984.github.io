## 🚀 How to use the utility

Once the program opens, you see several controls for different game mechanics.

### Rapid Targeting
The rapid targeting feature identifies nodes in the game environment. Toggle this setting to allow the script to snap your character toward flowers or resources. You save time by skipping the manual movement required to line up your character.

### Teleport Presets
The script includes saved coordinates for common map locations. Select a preset from the menu to move your character to fields, shops, or hives instantly. This avoids long walking times between different parts of the game map.

### Routine Controls
You manage your gameplay loops through the toggle menu. Enable specific tasks such as pollen collection, conversion, or boss fights. The program runs these cycles until you deactivate the switch. You retain control by monitoring the status lights on the dashboard.

## 🛠️ Troubleshooting

If the utility fails to start or behaves strangely, follow these fixes:

*   **Restart the program**: Close the window and launch it again as an administrator.
*   **Check Windows Defender**: Sometimes antivirus software blocks scripts. Add an exclusion for the script folder in your security settings.
*   **Update Roblox**: Ensure your game client runs the latest version. Mismatches between the game and the script lead to crashes.
*   **Verify Internet Connection**: Unstable internet causes the teleport feature to fail or your character to disconnect.
